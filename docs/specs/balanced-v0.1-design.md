# Clash 均衡节点监控 v0.1.0 设计规格

## 目标

在不接管 Clash Verge、不修改订阅节点、不显著增加后台资源占用的前提下，自动选择同时适合 Google、GitHub、ChatGPT、Gemini 与 Steam 交互服务的节点。选择以长期稳定为第一目标，并综合平台可用性、响应速度、抖动、吞吐和倍率。

## 判断原则

地区名称不是兼容性结论。台湾节点与其他普通候选完全同等：不优先、不降权、不跳过。节点名只用于展示和辅助诊断；选择依据来自该节点经过独立探测通道时的实际结果。

程序不声称能够在无账号、无浏览器会话的后台完整验证 ChatGPT 对话与 Gemini 生成功能。检测状态分为：

- `Compatible`：所有可由后台可靠验证的服务均通过，且没有待确认项。
- `BasicCompatible`：硬性网络检查通过，AI 页面、登录入口或 Cloudflare 验证链路可达，但账号内功能未验证；可以参与自动择优。
- `Unknown`：证据不足或结果互相矛盾；保留当前连接，不据此自动切换。
- `RegionBlocked`：响应明确表示地区不支持。
- `ServiceFailed`：服务返回明确的非验证类错误。
- `Transient`：超时、连接中断或临时网络错误。

只有检测证据能形成状态；不得根据“香港”“台湾”“日本”等节点名直接产生通过或失败结论。若未来加入地区快速跳过，只能依据独立探测得到的实际出口地区和可更新的平台支持数据，并允许用户关闭。

## 流量策略

- 微信、B站及其他国内服务继续由 Clash 现有规则直连，不纳入代理节点兼容性要求。
- Steam 游戏内容下载保持直连；商店、社区、聊天和 Web API 参与代理兼容性检测。
- Google、GitHub、ChatGPT、Gemini 及已启用的 Discord、Spotify、Epic 交互流量使用统一稳定节点。
- 所有候选探测通过独立的 `127.0.0.1:7896` 监听器完成，不影响当前用户连接，只有最终切换会修改统一稳定节点选择器。

## 候选与检测

候选仅进行结构性过滤：必须是实际代理节点、倍率可解析且不高于 3 倍、去重。不得按地区名称过滤。

每轮先检查当前节点。正常周期不扫描全部节点；在订阅变化、当前节点明确失败或六小时质量刷新到期时：

1. 用轻量延迟检测从全部候选预选最多 8 个，同时保留当前节点。
2. 对预选节点依次检查 Google、GitHub、ChatGPT、Gemini、Steam 商店、社区和 API。
3. 明确地区或服务失败时提前终止该节点；AI 验证页或登录页记录为基础可用并继续检查其他平台。
4. 仅本轮新鲜验证为 `Compatible` 或 `BasicCompatible` 的节点进入排名。
5. 网络繁忙时推迟吞吐测试；一次质量刷新最多下载 5 MiB 测试数据。

每个服务探测必须执行真实总超时，包含响应正文读取，避免单个站点拖住整个扫描。完整刷新应有明确日志起止与耗时。

## 均衡评分与切换

初版沿用可解释的 100 分制：稳定性 40、响应与抖动 25、吞吐 25、倍率成本 10。平台兼容性作为进入排名的门槛，不与速度分互相抵消；明确失败的高速节点不能胜出。

候选间响应指标必须使用同一种测量口径。轻量延迟只用于预选，不得拿当前节点的多平台平均耗时与其他节点的单一 Google 延迟直接比较。

自动切换同时满足：目标本轮已验证、相对当前综合分至少提高 20%、距离上次切换至少 10 分钟。当前节点完全断网时可跳过持有期，但仍只能切往本轮已验证候选。`Unknown` 不累计故障次数。

## 可见性与资源约束

Clash 首页固定展示“统一稳定节点”组，使节点栏显示实际叶节点名称。后台另写入 `current-status.txt`，包含版本、检测时间、实际节点、状态、检测说明、综合分和最近切换原因；不得记录订阅地址、密钥或节点凭据。

程序采用单进程、单实例、串行小批量探测；闲置工作集目标低于 15 MiB，日志上限 1 MiB，历史状态上限 256 KiB。异常不得造成每分钟全量重扫。

## 安装、升级与回滚

v0.1.0 提供 README、构建、安装、仅监控器安全升级和卸载说明。升级时：

- 先备份旧 EXE、状态和日志。
- 不重启 Clash Verge，不覆盖订阅、不更改节点列表。
- 替换后运行自检并保证只有一个后台进程。
- 对 Clash 关键配置做升级前后哈希比对；任何变化立即回滚监控器。

## 验收标准

- 台湾节点通过候选过滤测试，和新加坡、日本、美国等节点同等参与预选。
- 节点名称中的地区词不会单独决定兼容状态。
- Cloudflare 验证页与 Google 登录页只能产生 `BasicCompatible`，不能产生完整兼容声明。
- 明确地区阻止、服务失败、临时超时和待验证状态分别有自动化测试。
- 当前与候选使用同口径响应数据评分。
- 测试、构建、增强脚本测试和安装后自检全部通过。
- 实机确认节点数量不变、配置哈希不变、首页显示真实节点、后台状态更新、闲置内存符合目标。

## 非目标

v0.1.0 不自动登录网站、不读取 Cookie 或账号信息、不承诺消除网站自身故障或账号风控，不充当游戏专线加速器，也不根据一次体验自动永久封禁整个地区。
