# v0.6.2 — 可选浏览器真实对话验证

本版为选择 ChatGPT 或 Gemini 的用户增加 Chrome/Edge 浏览器伴侣。用户先一次性加载已解压的扩展，保持官网账号登录，再在节点守护中选择“自动实测当前节点”。伴侣会在官方网页自动发送带随机口令的短消息、自动判断新生成回复、自动关闭它创建的测试标签页。测试对话会保留，不自动删除。

后台自动实测默认关闭，只有明确授权才会运行；也可只进行本次实测。失败后的后台自动重试冷却 6 小时，手动重试不受影响。实测结果绑定当前节点、订阅与所选服务、加密出口指纹和验证规则，最多保留 30 天；出口变化、规则升级或明确失败会使结果失效。它验证的是官网网页对话，不是 API 密钥调用，也不保证以后每次生成正常。

未登录、验证码或安全挑战、网页结构暂不支持会分别显示，不直接算作节点故障。仅在消息确实发送后发生明确服务错误或等待回复超时，程序才先复检旧节点，并在安全条件满足时回退。当前健康节点的性能寻优仍默认关闭；故障容灾保留连续失败确认。历史寻优仍需至少 5 次、跨度 30 分钟、成功率不低于 95% 的记录。

扩展只请求 `nativeMessaging` 和 `https://chatgpt.com/*`、`https://gemini.google.com/*` 两个网站范围，不请求 Cookie 或浏览历史权限，不读取账号标识或既有对话。它会检查本次新回复以核对口令，但不会在本地状态或日志中保存消息与回复正文。安装器仅为当前用户注册 Chrome/Edge 本机消息宿主；不会修改 Clash 配置文件或订阅。浏览器中开发版扩展仍需用户手动加载和移除。

这是早期功能。网站页面结构、账号状态和安全挑战可能使自动化暂时无法完成。报告兼容问题时请提交脱敏诊断，不要附上账号、对话、Cookie、完整日志、订阅链接或 Clash 配置。
