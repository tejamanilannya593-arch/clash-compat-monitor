# ClashCompatibilityMonitor v0.7.0-preview.19

节点选择以 ChatGPT 实测响应为第一优先级；Steam API 与 Google 的实测响应仅在 ChatGPT 同分时决定次序。ChatGPT 不可用的候选排在可用候选之后，Clash 延迟仍只用于初筛。

固定必检服务由四项改为 ChatGPT、Steam API、Google 三项。Gemini 从默认服务、旧偏好、自动扫描、候选表格和故障按钮中移除，不再因其不可用拒绝 ChatGPT 可用的候选。实际出口仍须位于 ChatGPT 官方支持地区，切换前仍完整复检全部已选服务。

当前节点三项任一明确故障且本机有以太网或 Wi-Fi 连接时，后台继续按 30 秒周期轮换搜索；每轮最多检查 8 个候选。切换预算、观察、安全回退和公共服务事故归因规则保持不变。程序不修改 Clash 配置或订阅文件。
