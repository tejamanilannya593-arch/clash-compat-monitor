# ClashCompatibilityMonitor v0.7.0-preview.24

## 优化

- 将 200 ms（含）设为强制性能改善线。候选完整复检后，关键网站实测响应至少快 200 ms 就必须切换，不再同时要求百分比改善。
- 强制性能改善不受两次／十分钟、四次／三十分钟的性能寻优切换预算阻挡，也不会因近期切换而提高百分比门槛。
- 199 ms 及以下不触发强制规则，继续遵守普通稳定与预算策略。
- 强制切换仍要求实际出口地区合格，ChatGPT、Steam API、Google 及全部已选服务完整复检通过，且当前代理组仍保持预期节点；切换后观察和安全回退不变。

## 验证

- 新增 199 ms、200 ms 和近期切换三组边界测试。
- 新增性能预算耗尽时，普通寻优确认与严重延迟恢复仍执行强制切换的编排测试。
- 完整构建、增强脚本测试与发布检查通过后生成发布包。
