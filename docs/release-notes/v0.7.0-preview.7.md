# v0.7.0-preview.7 — 自动决策状态机与防抖

- 自动监测、故障恢复、性能寻优、切换观察和安全回退统一由可持久化状态机协调，重启后可安全恢复或终止未完成事务。
- 明确区分硬故障与严重性能退化：硬故障优先容灾；仅性能变慢时必须找到真正显著更快的完整合格候选才会切换。
- 性能切换同时要求相对改善至少 20% 和绝对改善至少 200 ms；最近十分钟发生过自动切换时，相对门槛提高到 30%。
- 自动切换预算限制为滚动十分钟最多 2 次、三十分钟最多 4 次；达到预算后进入稳定观察，但明确硬故障仍可继续容灾。
- 主动寻优继续使用全节点实时延迟初筛、真实服务 P75 排名、全部已选服务完整验证和 30 秒二次确认。
- 所有自动选择器写入统一经过状态授权、来源节点复核和 Mihomo 结果确认；手动切换会取消自动事务并进入冷却期。
- 决策日志记录前后状态、事件、证据、动作、改善阈值及切换预算，不记录原始出口 IP。
- 不修改 Clash 配置文件或订阅文件，只更新现有代理组选择。
