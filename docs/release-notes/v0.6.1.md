# Clash Compatibility Monitor v0.6.1

v0.6.1 是一次以“证据可信、少误切”为中心的修复版本。它不再把单个入口页或 Cloudflare 验证页的可达性当作 ChatGPT、Gemini 完整可用，也不根据节点名称猜测地区能力。

## 主要变化

- ChatGPT 与 Gemini 使用应用入口加官方认证端点的双端点登录链路检测。
- ChatGPT 支持地区依据实际出口国家/地区判断；原始出口 IP 不落盘，只生成本机密钥保护的指纹。
- 新增低操作的账号实测对话框：打开官方页面，用户实际登录并各发送一条最短消息后确认结果。
- 账号实测有效 30 天，并绑定订阅与服务组合、节点、出口指纹和证据规则版本；出口变化、明确失败或规则升级会失效。
- 当前节点仅入口可达时显示待验证，不再显示“运行正常”，也不能成为自动切换目标。
- 性能寻优同时要求严格探测、账号实测、至少 5 次且跨 30 分钟的 95% 成功历史、中位延迟不超过 800 ms、单次和本轮单服务不超过 1500 ms、抖动不超过 150 ms，以及至少 20% 综合提升。
- 故障容灾仍采用连续失败确认。紧急目标如果尚未账号实测，会进入临时观察；第一次明确服务失败就复检旧节点，旧节点通过则回退。
- 延迟显示统一为：不超过 500 ms“优秀”，501–800 ms“良好”，801–1500 ms“可连接但偏慢”，超过 1500 ms“不适合自动寻优”。这里测量的是轻量 HTTP 响应，不是 AI 实际生成延迟。
- 移除 JMComic 网页检测及当前 UI 入口；旧版偏好中的 JMComic 项会在加载时安全忽略并在下次保存时清理，不影响其他服务选择。

## 隐私边界

账号实测完全由用户在默认浏览器的官方页面完成。程序不读取 Cookie、账号、提示词、回复、浏览历史或浏览器状态，不保存原始出口 IP，也不上传遥测。

## 升级

下载并完整解压 `ClashCompatibilityMonitor-v0.6.1.zip`，运行 `Install.cmd`。安装器会备份现有程序、状态与日志，只替换守护程序，不改订阅内容，也不重启 Clash。

升级后建议在详情页对当前常用节点完成一次 AI 账号实测。未实测不会中断当前可用连接，只会阻止以性能为目的主动切换到该节点。
