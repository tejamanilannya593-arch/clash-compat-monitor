# ClashCompatibilityMonitor v0.7.0-preview.27

- 稳定期与预算稳定状态不再阻止自动寻优发现候选；仍按正常的 3 分钟间隔实测，不增加每分钟检测负担。
- 候选完成实际出口地区和全部所选服务复检后，只要主要网站响应至少快 200 ms（含），立即绕过稳定期和切换预算执行切换。
- 完整复检仅改善 199 ms 或更少时保持当前节点，并继续检查排行中的后续候选，避免小幅波动抢先挡住真正达到强制阈值的节点。
- 保留切换后的观察、异常回退、服务侧事故抑制、前台大流量保护和代理路径一致性检查。
- 回归测试覆盖 Cooldown 下 199 ms 不切、Stabilization 下恰好 200 ms 切换，以及首位不足阈值时继续选择后位合格节点。
