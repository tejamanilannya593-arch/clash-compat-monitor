# ClashCompatibilityMonitor v0.7.0-preview.13

## 本次变化

- 启用“当前节点可用时允许性能寻优”后，后台约每三分钟自动测量一次候选网站延迟排行；当前节点可用也会参与更快节点的选择。
- 并发获取全部叶子节点本轮 Clash 延迟，先取前 10 个候选，逐个实测全部已选网站，并以网站响应 P75 排名。
- 按表格第一名到第十名依次完整复检。候选的实际出口必须处于 ChatGPT 与 Gemini 官方支持地区交集，全部已选服务须通过网络验证，且复检响应须快于当前节点。第一名复检失败会尝试下一名。
- 找到合格节点后直接切换；保留流量保护、自动切换预算、切换后观察和安全回退。当前节点更快或没有合格候选时保持原节点。
- “重新实测前 10 名”仍只刷新表格，不单独触发切换；入口可达但尚未完整验证的结果同时显示延迟与验证状态。
- 演练模式与服务设置变化期间不会因旧排行切换。

## 使用

在详情页启用“当前节点可用时允许性能寻优”并保存。后台会自动更新“候选网站延迟排行”和节点选择。首次安装的该选项仍默认关闭；明确故障的快速容灾不依赖此选项。

## 安全边界

- 只操作现有代理组选择，不修改 Clash 配置或订阅文件。
- 轻量网站探测和匿名登录链路验证不代表账号内真实对话通过。
- 原始服务器、端口、UUID、密码、SNI 和出口 IP 不写入日志或状态文件。
