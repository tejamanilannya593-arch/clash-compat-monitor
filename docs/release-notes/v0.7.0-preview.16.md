# ClashCompatibilityMonitor v0.7.0-preview.16

## 本次改进

- 候选最终排序优先比较 ChatGPT 与 Gemini 的真实网站响应：两者中较慢的一项作为主指标；主指标相同时，再比较 Steam API 与 Google 两者中较慢的一项。
- Clash/Mihomo 延迟仅用于确定有限候选的探测顺序和前十名初筛，不再参与已验证候选的最终排名。
- 故障快速检测固定覆盖 ChatGPT、Gemini、Steam API、Google 和 GitHub；最终切换仍须通过用户全部已选服务及实际出口地区验证。
- 候选排行表按相同优先级排序、排列网站列，并明确标注 Clash 延迟只是初筛参考。
- 日常性能寻优以 ChatGPT/Gemini 实测响应比较当前节点与候选节点，保留完整复检、切换预算及观察回退。

程序不修改 Clash 配置或订阅文件。
