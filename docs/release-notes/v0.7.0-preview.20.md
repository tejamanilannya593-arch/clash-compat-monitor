# ClashCompatibilityMonitor v0.7.0-preview.20

长期守护链路增加进程启动、正常停止、UI 线程、协调线程和重复启动激活回调的本地日志。单个界面回调异常不再中断其余通知；协调线程遇到未预期异常时会进入降级状态，并在 5 秒后重新开始检测。登录自启改用受限启动器：正常从托盘退出不重启，异常退出最多重试 3 次且每次间隔 5 秒。

候选网站延迟排行新增“未入选原因”，区分 ChatGPT、Steam API、Google 或其他已选服务未通过、实际出口地区不合格、完整复检失败、实测未优于当前节点、改善不足、切换预算限制、切换未执行和最终选中。

切换策略保持稳定优先：确认的硬故障继续绕过性能寻优预算以恢复连接；仅响应过慢和主动性能寻优仍受两次/十分钟、四次/三十分钟的滚动预算限制。程序仍只操作代理组选择，不修改 Clash 配置或订阅文件。
