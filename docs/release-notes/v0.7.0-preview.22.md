# ClashCompatibilityMonitor v0.7.0-preview.22

## 修复

- 修复登录 Windows 后自启动快捷方式弹出“无法找到脚本文件 `launcher.vbs`”、守护进程未启动的问题。
- 开机快捷方式改为直接指向已安装的 `ClashCompatibilityMonitor.exe`，通过 `--startup-supervisor` 进入内置监督模式，不再依赖独立脚本文件。
- 内置监督模式在守护进程异常退出时最多重试 3 次，每次间隔 5 秒；用户从托盘正常退出时不会重新启动。
- 安装程序会停止并清理旧的 WSH 启动器，升级失败时仍恢复旧程序、旧快捷方式和备份状态。

## 验证

- 命令行解析和异常重启边界均有自动化测试。
- 发布检查确认开机快捷方式直接指向主程序，发布包不再依赖 `launcher.vbs`。
- 安装后同时核对监督进程、守护进程、自启动快捷方式和实际检测周期。
