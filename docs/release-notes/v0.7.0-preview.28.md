# ClashCompatibilityMonitor v0.7.0-preview.28

- 新增检测进度心跳：工作进程仍存在但连续 3 分钟没有检测进度时，开机监督进程会结束假活进程并立即重启。
- 暂停状态和正常周期等待会定时报活，避免将用户暂停或常规空闲误判为卡死。
- 安装器不再依赖可能被应用容器重定向的 `LocalApplicationData`，改为解析真实用户目录下的 `AppData\Local`。
- 升级时可识别并停止旧自启动快捷方式指向的 `Packages\...\LocalCache` 实例，避免旧实例占用单例锁导致新版静默退出。
- 回归测试覆盖心跳参数、跨进程信号、3 分钟失活判定和物理安装路径约束。
