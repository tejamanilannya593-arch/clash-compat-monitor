# ClashCompatibilityMonitor v0.7.0-preview.23

## 优化

- 详情页和托盘菜单将“立即复检当前节点”与“立即寻优并切换”拆分，避免把只刷新状态误认为会触发节点选择。
- 用户明确发起立即寻优时，跳过自动寻优的稳定期、三分钟扫描间隔和自动切换预算；候选仍必须实测快于当前节点，并通过实际出口地区、ChatGPT、Steam API、Google 及全部已选服务的完整复检。
- 普通自动寻优继续遵守切换预算与稳定期；状态页会显示稳定期截止时间，并提示可使用“立即寻优并切换”。
- 候选排行把“未入选原因”固定在节点名称旁边，横向查看网站延迟时也不会隐藏；表格刷新按钮仍只测速，不改变当前节点。
- 安装升级可识别 Windows 应用包重定向路径中的监督进程和工作进程，先完整停止旧实例再替换 EXE，避免因文件仍被占用而升级失败。

## 验证

- 新增稳定期和四次／三十分钟预算均已耗尽时的手动寻优回归测试，确认完整复检通过后仍可按用户指令切换。
- 新增协调器触发语义、详情页按钮及候选表固定原因列的自动化测试。
- 完整构建、核心测试、增强脚本测试与发布检查通过后生成发布包。
