# ClashCompatibilityMonitor v0.7.0-preview.29

- ChatGPT 故障恢复会记录自动切换时的失败服务，并在后续快速恢复中识别刚因同一服务故障被切走的节点。
- 最近 10 分钟的同服务故障节点排在新鲜候选之后，避免几十秒内在两个不稳定节点之间来回切换。
- 防抖只调整复检顺序，不封禁候选；若最近失败节点是唯一完整复检通过的节点，仍在当前轮次立即切换。
- 保留全部低 Clash 延迟节点的 ChatGPT 快速实测、ChatGPT 延迟优先排序、Steam API／Google 等固定核心网站完整复检及 3 秒快速重试。
- 回归测试覆盖同服务防抖、10 分钟自动失效、跨服务互不影响、唯一候选立即兜底和切换记录持久化。
