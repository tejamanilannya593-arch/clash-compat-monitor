# ClashCompatibilityMonitor v0.7.0-preview.11

## 本次变化

- 使用本机密钥为真实代理连接生成不可逆的稳定节点身份，不再把显示名称当作持久信任主键。
- 节点改名后可继续使用同一物理节点的质量、地区与稳定性历史；同名节点的连接材料变化后会冷启动。
- preview.10 的名称型历史仍可读取，但不能授权自动切换、回退、备用、地区资格或账号验证。
- 身份无法确认的节点仍可在明确硬故障时通过本轮完整实测临时接管，但不能参加主动性能寻优或积累长期信任。
- 解析当前生效的 Clash 配置与订阅来源时保持只读，并限制文件大小、节点数和字段长度。
- 原始服务器、端口、UUID、密码和 SNI 不写入 Monitor 日志或状态文件。

## 保持不变的安全边界

- 健康状态最长 60 秒自动复检，故障和切换观察阶段 30 秒复检，无需点击“立即复检”。
- 明确硬故障优先快速容灾；性能切换仍需五个样本、绝对与相对收益、30 秒确认、预算、观察和安全回退。
- 候选仍必须通过 ChatGPT 与 Gemini 官方支持地区交集以及用户全部已选服务验证。
- 程序只操作代理组选择，不修改 Clash 配置或订阅文件。

## 升级与验证

使用本版本文件夹内的 `scripts\install.ps1` 从 preview.10 升级。preview.10 的名称型长期历史会安全冷启动。安装后确认：

- 产品版本为 `0.7.0-preview.11`；
- 只有一个守护进程，开机启动快捷方式指向当前安装目录；
- 至少两个 `cycle trigger=scheduled` 自动周期无需手动复检即可出现；
- 安装前后的 Clash 配置和订阅文件 SHA-256 完全一致。
