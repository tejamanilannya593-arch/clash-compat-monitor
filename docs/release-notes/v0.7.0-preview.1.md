# v0.7.0-preview.1 — 结构化候选与配置写入边界

- 候选节点除原有名称去重外，使用 Mihomo 返回的实际代理类型和子选项结构排除 Direct、Reject、选择组、自动测速组等非叶节点；未知类型但含子选项的组也会排除，不按国家、地区或机场命名筛选。类型目录暂不可读时回退到原方式，避免某些订阅整轮无候选。
- 后台不再调用 Mihomo 的整份运行配置热重载接口。若运行时 IPv6 意外开启，会暂停本轮并提示重新应用现有增强脚本；不会偷偷修改 Clash 配置。
- 保留故障容灾、普通代理组跟随和逐站点代理路径诊断。旧版依赖配置热重载的自动恢复旧节点在此预览版暂停；手动恢复上一个节点仍需现场复检。

本预览版不保证网站账号登录、AI 实际对话或所有机场节点均可用；不是 GitHub 正式版。
