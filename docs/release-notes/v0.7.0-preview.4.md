# v0.7.0-preview.4 — 快速故障切换

- 当前节点出现明确地区限制或服务拒绝时，直接进入备用节点现场验证，不再重复检测当前节点。
- 普通网络超时仍快速复检一次，避免单次抖动造成误切。
- 对全部候选并发读取 Mihomo 延迟，按低延迟顺序最多现场验证 8 个；候选通过故障服务、完整基础检测且所有单项低于 2000 ms 后立即切换，不等待综合测速排名。
- 故障救援允许使用基础网络兼容的临时目标，并在切换后观察；第一次明确失败即可触发旧节点复检与回退。
- 移除正常周期前的串行双路径诊断，避免每轮额外等待；选择组发生实际对齐变更时才进行路径诊断。
- 正式程序、界面和发布包移除浏览器伴侣；升级安装会备份并清理旧宿主、扩展目录和注册项。
- 软件仍不会修改 Clash 订阅或配置文件，只操作现有代理组的节点选择。
