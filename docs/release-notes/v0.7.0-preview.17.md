# ClashCompatibilityMonitor v0.7.0-preview.17

## 本次改进

- ChatGPT、Gemini、Steam API、Google 固定为自动守护的四项必检服务；旧偏好在读取时自动补齐，设置页不再允许关闭其中任一项。
- 当前节点四站任一明确不可连接时，自动进入候选恢复；候选必须四站均可连接、实际出口地区合规，且通过其他已选服务的完整复检后才能切换。
- 每轮快速恢复最多检查 8 个候选；未找到合格节点时保存搜索位置，下一自动周期继续检查后面的候选，而不是重复检查同一批。
- 以太网和 Wi-Fi 均未连接时暂停节点搜索与切换，每 30 秒重新检查本机网络；恢复后继续自动守护。
- 保留用户暂停、单轮时间预算、切换预算、观察及安全回退保护。

“可连接”指网站网络入口或登录链路的探测通过，不代表已登录或完成真实 AI 对话。程序不修改 Clash 配置或订阅文件。
