# ClashCompatibilityMonitor v0.7.0-preview.25

## 修复

- 修复后台检测、容灾切换继续运行时，`current-status.txt` 可能因文件查看器阻止原子替换而长期停留在旧周期的问题。
- 状态发布始终采用原子替换；读取程序阻止替换时，旧状态保持完整，新状态完整保留在临时文件中供后续周期重试。
- 文件被完全锁定或权限暂不可用时，记录不含路径和内容的有限错误类型，并继续完成监测周期，不执行可能留下半截内容的原地覆盖。
- 状态文件故障不会影响节点检测、自动选择、观察、回退或持久化的决策状态。
- 安装器只自动停止路径可确认属于安装目录的实例；WMI 因权限隐藏路径时会给出明确关闭提示，不会仅凭进程名终止同名程序。

## 保持不变

- 候选通过完整安全复检后，关键网站实测响应至少快 200 ms 时必须切换。
- 实际出口地区、ChatGPT、Steam API、Google、全部已选服务、选择器一致性、切换后观察和安全回退规则不变。

## 验证

- 新增“读取器阻止替换时保留旧状态与完整临时状态”“释放后原子重试”以及“文件被完全锁定”回归测试。
- 完整构建、增强脚本测试与发布检查通过后生成发布包。
