# ClashCompatibilityMonitor v0.7.0-preview.10

## 本次变化

- 当前节点至少积累 5 个性能样本后，才允许启动主动性能寻优。
- 每个节点只保留最近 10 个响应样本，旧样本不会长期影响当前判断。
- 统一计算 Median、P75 和 P90；抖动使用 `P90 - Median`，可识别单次或少量尾部尖峰。
- 候选节点除中位响应和单次最大响应外，还必须通过尾部抖动门槛。
- 历史节点排名使用真实成功次数与总检测次数计算失败率，不再只依赖平滑成功值。
- 自动周期和完整质量比较均读取相同的十样本窗口，手动复检与定时检测继续共用相同安全门槛。

## 保持不变的安全边界

- 明确硬故障仍优先进入快速容灾，不等待五个性能样本。
- 性能切换仍须通过全部已选服务、官方地区交集、收益门槛、30 秒确认、切换预算、观察和安全回退。
- 所有叶子节点的 Mihomo 延迟仍只并发检测一次，单节点上限 2500 ms。
- 最多检查 8 个候选，找到 3 个合格候选后停止。
- 程序只操作代理组选择，不修改 Clash 配置或订阅文件。

## 升级与验证

使用本版本文件夹内的 `scripts\install.ps1` 从 preview.9 升级。安装后应确认：

- 产品版本为 `0.7.0-preview.10`；
- 只有一个守护进程；
- 开机启动快捷方式指向当前安装目录；
- 至少两个 `cycle trigger=scheduled` 自动周期无需点击“立即复检”即可出现；
- 安装前后的 Clash 配置和订阅文件 SHA-256 完全一致。
