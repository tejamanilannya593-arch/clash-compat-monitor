# v0.6.3-preview.1 — Z-Library 网页入口检测预览

本预览版新增默认关闭的“Z-Library 网页”选项，仅访问用户指定的 `https://zh.z-library.sk/`，检测网页入口的 HTTP 响应和延迟。HTTP 200 显示“入口可达”；验证码页、登录挑战或跳转只显示“仅确认可达”。这不验证账号登录、图书搜索或下载，也不自动寻找其他域名。

同时保留详情页数字字体和按屏幕缩放调整服务状态列宽的修正。浏览器伴侣协议与扩展仍为 0.6.2，无需为此功能重新配置扩展。

这是本地预览包，不是 GitHub 正式版。安装程序会先诊断、备份旧程序和状态，安装后核对 Clash 受保护配置文件未变化；若验证失败会尝试恢复旧程序。当前站点在本机代理的只读请求返回过 HTTP 307，因此实际显示可能是“仅确认可达”，不应由此断言所有节点不可用。
