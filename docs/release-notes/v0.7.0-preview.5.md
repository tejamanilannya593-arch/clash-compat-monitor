# v0.7.0-preview.5 — 实际出口地区与自动恢复

- ChatGPT 与 Gemini 改为固定核心组合，旧偏好会自动迁移，不能只启用其中一个。
- 先按实际出口判断 ChatGPT 与 Gemini 官方支持地区交集，不根据节点名称猜测地区；香港出口不会作为 AI 通用节点。
- 全部叶子节点的 Mihomo 延迟并发初筛，按本轮实时延迟最多检查 8 个；找到延迟最低的三个合格候选后停止扫描。
- 最终按关键服务真实 P75 延迟选择，Mihomo 延迟只用于同分处理；第一名完整复检失败会自动尝试下一名。
- 800 ms 以内显示“实测优质节点”；更慢的胜出候选会明确说明尚未达到 800 ms 优质标准。
- 健康状态下每 60 秒自动复检，当前故障或切换观察期每 30 秒复检，无需点击“立即复检”。
- 服务熔断不再排除当前节点的已选服务，也不覆盖本轮真实结果；恢复后的候选可以被自动发现并用于故障切换。
- 公共服务事故的真实结果可用于当前决策和界面显示，但不会污染节点健康、质量和稳定率历史。
- 候选完整复检和自动回退前复检均覆盖全部已选服务，不能切换或回退到仍有相同故障的节点。
- 服务表格按窗口和 DPI 自动分配三列宽度，显示全部实际检测服务并避免横向滚动条。
- 不修改 Clash 配置文件或订阅文件，只更新现有代理组选择。

匿名 HTTP 入口和登录链路检测不等同于已登录的 ChatGPT 或 Gemini 真实对话，也不能保证之后的生成质量。
