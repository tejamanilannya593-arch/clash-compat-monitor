# v0.7.0-preview.6 — 五分钟主动寻优

- 启用自动优化且当前节点最近三次综合响应中位数持续超过 800 ms 时，最迟每三分钟启动一次主动机会扫描，无需点击“立即复检”。
- 一次并发取得全部叶子节点的 Mihomo 实时延迟，最多快速检查 8 个候选，找到 3 个可比较候选后停止。
- 候选按真实服务响应 P75 排名；最佳候选必须完整检测用户选择的全部服务，并在 30 秒后与当前节点一起再次确认。
- 目标复检仍不超过 800 ms 且比当前节点至少快 20% 才会切换；切换后继续使用原有观察与安全回退。
- 主动比较允许实际出口位于 ChatGPT 与 Gemini 官方支持地区交集、全部必需服务证据完整且单项不超过 1500 ms 的 `BasicCompatible` 节点参与排名，但不会把它重新标记为完整兼容，也不代表账号登录或真实对话已验证。
- “立即复检”和后台自动周期使用相同的地区、服务、流量、代理路径、事故熔断、冷却与回退门槛；触发来源只用于日志诊断。
- 五分钟是正常条件下的发现与确认目标；暂停、Mihomo 不可用、代理冲突、服务事故或前台大流量保护会推迟主动寻优。
- 不修改 Clash 配置文件或订阅文件，只更新现有代理组选择。
