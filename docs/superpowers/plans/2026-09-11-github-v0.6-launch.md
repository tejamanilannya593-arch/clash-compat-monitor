# GitHub v0.6.0 Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified local v0.6.0 as a trustworthy, understandable, and downloadable GitHub project without rewriting existing history.

**Architecture:** Preserve the stacked PR history by merging PR #1 first and evolving PR #2 into the v0.6.0 release PR. Separate repository-facing work into community/security files, README and visual assets, and release automation; gate every public mutation on local tests and GitHub checks.

**Tech Stack:** C#/.NET Framework, PowerShell, Node.js, Git/GitHub CLI, GitHub Actions, Markdown, PNG assets.

```powershell
$archiveHash = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
```
