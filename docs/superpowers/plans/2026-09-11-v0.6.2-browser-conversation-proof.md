# v0.6.2 Browser Conversation Proof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace subjective AI account feedback with an optional Chrome/Edge companion that sends one fixed challenge, verifies the matching reply, closes its tab, and records a node-and-exit-bound conversation proof.

**Architecture:** A Manifest V3 extension keeps a native-messaging connection to a small second executable. The host forwards bounded request/response JSON frames to the tray process over a current-user named pipe; the tray process owns task state, consent, rate limits, node/exit validation, and rollback decisions. The extension uses exact-site content adapters and returns only an outcome enum, elapsed time, and the generated challenge identifier.

**Tech Stack:** C#/.NET Framework 4.x compiled with `csc.exe`, WinForms, named pipes, `JavaScriptSerializer`, Chrome Manifest V3, plain JavaScript with Node-based tests, PowerShell packaging and installer tests.
